# AI协作记录与导出范围

本目录保存本题可取得的原始可见会话事件及豆包材料，不以总结代替原记录。

- `manifest.json`：快照UTC时间、会话ID、主/子任务来源、原始行数、导出条数、排除类别及SHA-256。
- `codex/*.jsonl`：本项目主会话及实现/最终review子任务的可见用户/助手消息、函数调用和工具结果。每条含source_line与原始record对象；事件消息与响应消息可能重复，保留而非重写。
- `doubao/`：豆包的分析/评审产物（11 份）与 `doubao/README.md` 索引；不宣称是豆包完整聊天导出，完整会话由用户另行导出。
- `index.md`：关键人工判断、任务分工、TDD证据和缺失说明。

导出仅选本项目工作目录对应会话；排除系统/开发者上下文、隐藏推理、统计及无关元数据。邮箱和疑似API密钥脱敏，虚构本地测试Token保留。未收集任何配置密钥文件。

豆包完整聊天目前未取得，仅有用户提供的分析/review文件；此项属于协作记录缺失，不能用这些文件或总结冒充完整聊天。工具已截断的内容只能交可取得部分。快照之后的尾部尚未包含，截止时间见manifest。正在追加文件若末行未完成，下次快照才取得。

哈希针对经过选择和脱敏的导出文件，不声称是未经处理的原始会话文件哈希。
